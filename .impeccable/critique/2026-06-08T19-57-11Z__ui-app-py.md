## Anti-Patterns Verdict
- Deterministic in-page scan (bundled browser detector file absent; ran equivalent computed-style scan): SIDE-STRIPE BORDERS confirmed on .ew-insight bad/good/info (border-left 5px brand colors, 6 instances) and .ew-turn-rep/cust (3px) on Call detail. No gradient text, no glassmorphism. BLOCKQUOTE 2px left border = Streamlit default.
- LLM: Takeaways leans on the hero-metric + identical-card-grid reflex (6 equal big-number cards, two near-duplicate pricing ones). Streamlit default chrome (Deploy button, hamburger, emoji logo) reads out-of-product.

## What's Working
1. Insight-first IA: plain-language takeaways lead, call-IDs replaced by account labels. Real win.
2. Editorial honesty: "directional, not statistical" disclaimer + per-chart "what this means" captions.
3. Coherent restrained dark palette; color is semantic (rose=lost, emerald=won), not decorative.

## Priority Issues
- [P1] Side-stripe borders (hard ban) on insight cards + transcript rows. Fix: full border + leading dot/chip or tinted block, not a stripe.
- [P1] Six insight cards = hero-metric/identical-grid reflex with redundancy. Fix: 1 lead insight + 2 supporting, distinct treatments, dedupe the two pricing cards.
- [P2] Inconsistent card vocabulary + Streamlit chrome. Fix: one card style; hide toolbar via config (toolbarMode viewer); real wordmark not emoji.
- [P2] Run page: headless AI run with bypassPermissions, no confirm/stop, free-text dates. Fix: confirm + date pickers + stop affordance + plain-language precondition errors.
- [P3] Verbose example chips run-on in headline cards. Fix: account-only, max 3.

## Persona Red Flags
- Sales VP (glance-and-go): "Deploy" button confusing; "Composite"/"Reach" unexplained; 6 cards before charts.
- RevOps analyst (power user): no export/CSV, no shareable filtered URL, no keyboard nav.
- Enablement manager: every pricing action item shows identical "97% n=33" reach -> reads copy-pasted, erodes trust in ranking.

## Minor Observations
- Limitation blockquote uses Streamlit default left-border (same family as the ban).
- Mint stat numbers (2rem/800) loud; let the claim carry weight.
- Donut charts feel small at fixed 320px.

## Questions to Consider
- What if Takeaways led with ONE full-width headline + a compact "3 more" strip instead of 6 equal cards?
- Should Run controls be hidden from the exec audience (admin-only route)?
- What single number should a sales leader leave with?
